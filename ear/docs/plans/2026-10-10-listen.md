# /listen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Claude an ear: a `/listen` skill that turns any audio, URL or video soundtrack into a measured report, frame-accurate `cues.json` and `curves.json`, spectrogram images and a hearing-model description.

**Architecture:** A Python toolkit in `cid/ear/` that mirrors `/watch`. A cached pipeline of single-purpose stages (ingest, stems, rhythm, hits, classify, structure, moments, mix, speech, hear, see, assemble) each reads earlier stages' JSON from `~/.cache/listen/<hash>/` and writes its own. Signal processing owns numbers and timestamps; Gemini owns words and labels; Claude cross-checks both against images.

**Tech Stack:** Python 3.12 via uv, librosa, beat_this, demucs (isolated through uvx), pyloudnorm, scipy, mlx-whisper, google-genai, pydantic, matplotlib, pytest; TypeScript helper for Remotion tested with Node 24's built-in test runner.

**Spec:** `ear/docs/specs/2026-10-10-listen-design.md`

## Global Constraints

- Platform: macOS on Apple Silicon only. Python pinned to 3.12 with uv (`requires-python = "==3.12.*"`).
- torch and torchaudio pinned to `2.5.1` in the analysis environment.
- demucs runs only through `uvx --python 3.11 --from demucs==4.0.1` so it never shares an environment with the analysis code.
- Cache root: `~/.cache/listen/` (override with `LISTEN_CACHE`). Config: `~/.config/listen/.env` (override dir with `LISTEN_CONFIG`).
- Every event carries `t` in seconds and `f` = `round(t * fps)`. Default fps is 60.
- All strengths, `v` values and curve samples are normalised to 0..1.
- Images: 6 to 12 by default, hard cap 16.
- `report.md` stays under 2,000 tokens (estimate: characters / 4).
- Exactly one hearing request per track (per chunk for inputs over 10 minutes). A cached hearing result with the same prompt hash is never re-requested.
- No em dashes or en dashes anywhere in generated text, docs, comments or UI strings. Write ranges as "0:00 to 0:15".
- External commands are always called with argument lists, never through a shell string.
- Commits: plain `git commit -m "..."` (global identity is already set). Never add `Co-Authored-By`, `Claude-Session`, or any Claude attribution.
- All paths in this plan are relative to `cid/ear/` unless written otherwise. Run every command from `cid/ear/`.

## Review Focus

1. **Odd file names and URLs** (spaces, quotes, parentheses, accents, `&` in a query string): must ingest without error. Pinned by `test_weird_filename_is_ingested` in Task 2.
2. **Mono, 48k, 96k or multichannel input**: must normalise to 44.1k stereo, and a mono source must not raise stereo flags. Pinned by `test_mono_48k_becomes_stereo_44k` in Task 2 and `test_mono_source_has_no_stereo_flags` in Task 9.
3. **Very quiet masters** (around -35 LUFS): silences and drops must still be found because thresholds are relative. Pinned by `test_quiet_master_still_finds_drop_and_silence` in Task 8.
4. **Interrupted run leaving a corrupt stage JSON**: must be treated as missing and rerun, never crash. Pinned by `test_corrupt_stage_json_is_treated_as_missing` in Task 1.
5. **Hearing model returns partial or mismatched section ids**: auto labels fill the gaps, a conflict is listed, no crash. Pinned by `test_partial_hearing_sections_fall_back_to_auto_labels` in Task 13.

```python
"""Per-run state shared by every stage."""
from __future__ import annotations

import json
import os
from dataclasses import dataclass, field
from pathlib import Path


def _np_default(o):
    import numpy as np

    if isinstance(o, np.generic):
        return o.item()
    if isinstance(o, np.ndarray):
        return o.tolist()
    raise TypeError(f"not JSON serialisable: {type(o).__name__}")


@dataclass
class Context:
    workdir: Path
    fps: int = 60
    fast: bool = False
    no_cloud: bool = False
    options: dict = field(default_factory=dict)

    def path(self, name: str) -> Path:
        return self.workdir / name

    def read(self, stage: str) -> dict:
        """Raw stage JSON, or {} when missing or unreadable."""
        try:
            return json.loads((self.workdir / f"{stage}.json").read_text())
        except (FileNotFoundError, json.JSONDecodeError):
            return {}

    def data(self, stage: str) -> dict | None:
        """Stage JSON if the stage produced usable output, else None."""
        d = self.read(stage)
        if not d or d.get("_unavailable"):
            return None
        return d

    def write(self, stage: str, data: dict) -> None:
        target = self.workdir / f"{stage}.json"
        tmp = target.with_suffix(".json.tmp")
        tmp.write_text(json.dumps(data, indent=1, default=_np_default))
        os.replace(tmp, target)
```

`core/pipeline.py`:

```python
"""Runs stages in order with per-stage caching and independent failure."""
from __future__ import annotations

from dataclasses import dataclass
from typing import Callable, Iterable

from core.context import Context


class Fatal(Exception):
    """Nothing useful can be produced (no audio, unreadable input). Stops the run."""


class StageUnavailable(Exception):
    """One stage cannot run. The reason is shown in the report; other stages continue."""


def _always(ctx: Context) -> bool:
    return True


@dataclass(frozen=True)
class Stage:
    name: str
    version: int
    deps: tuple[str, ...]
    run: Callable[[Context], dict]
    enabled: Callable[[Context], bool] = _always


def run_pipeline(ctx: Context, stages: Iterable[Stage], force: Iterable[str] = ()) -> dict[str, str]:
    force = set(force)
    status: dict[str, str] = {}
    rerun: set[str] = set()
    for st in stages:
        if not st.enabled(ctx):
            status[st.name] = "skipped"
            continue
        cached = ctx.read(st.name)
        stale = (
            st.name in force
            or cached.get("_v") != st.version
            or bool(cached.get("_unavailable"))
            or any(d in rerun for d in st.deps)
        )
        if not stale:
            status[st.name] = "cached"
            continue
        try:
            data = dict(st.run(ctx))
            data["_v"] = st.version
            data.pop("_unavailable", None)
            ctx.write(st.name, data)
            status[st.name] = "ok"
        except Fatal:
            raise
        except StageUnavailable as e:
            ctx.write(st.name, {"_v": st.version, "_unavailable": str(e)})
            status[st.name] = f"unavailable: {e}"
        except Exception as e:  # a broken stage must never take the whole run down
            reason = f"{type(e).__name__}: {e}"
            ctx.write(st.name, {"_v": st.version, "_unavailable": reason})
            status[st.name] = f"unavailable: {reason}"
        rerun.add(st.name)
    return status
```

`core/cache.py`:

```python
"""Content-hash cache keys."""
from __future__ import annotations

import hashlib
import os
from pathlib import Path


def cache_root() -> Path:
    return Path(os.environ.get("LISTEN_CACHE", Path.home() / ".cache" / "listen"))


def source_key(path: Path, start: float | None, end: float | None) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    key = h.hexdigest()[:16]
    if start is not None or end is not None:
        lo = f"{start:g}" if start is not None else "0"
        hi = f"{end:g}" if end is not None else "end"
        key += f"_{lo}-{hi}"
    return key
```

```python
"""Time parsing and formatting (SS, MM:SS, HH:MM:SS)."""
from __future__ import annotations


def parse_time(s: str) -> float:
    parts = str(s).strip().split(":")
    if not 1 <= len(parts) <= 3:
        raise ValueError(f"bad time: {s}")
    total = 0.0
    for p in parts:
        total = total * 60 + float(p)
    return total


def fmt_time(t: float, precise: bool = False) -> str:
    m, s = divmod(max(float(t), 0.0), 60)
    h, m = divmod(int(m), 60)
    sec = f"{s:05.2f}" if precise else f"{int(s):02d}"
    return f"{h}:{m:02d}:{sec}" if h else f"{m}:{sec}"
```

```python
"""Shared audio helpers. Analysis runs at 24 kHz so curves land on an exact 100 Hz grid."""
from __future__ import annotations

import numpy as np

ANALYSIS_SR = 24000
CURVE_HOP = 240
CURVE_HZ = ANALYSIS_SR // CURVE_HOP  # 100 samples per second


def load_mono(path, sr: int = ANALYSIS_SR) -> np.ndarray:
    import librosa

    y, _ = librosa.load(str(path), sr=sr, mono=True)
    return y


def norm01(x, pct: float = 99.0, floor: float | None = None) -> np.ndarray:
    x = np.asarray(x, dtype=float)
    if x.size == 0:
        return x
    lo = float(x.min()) if floor is None else float(floor)
    hi = float(np.percentile(x, pct))
    if hi - lo <= 1e-12:
        return np.zeros_like(x)
    return np.clip((x - lo) / (hi - lo), 0.0, 1.0)


def resample_curve(values, src_hz: float, fps: int, duration: float, offset: float = 0.0) -> np.ndarray:
    values = np.asarray(values, dtype=float)
    n = int(round(duration * fps))
    if values.size == 0:
        return np.zeros(n)
    src_t = offset + np.arange(values.size) / src_hz
    return np.interp(np.arange(n) / fps, src_t, values)


def onset_env(y: np.ndarray, sr: int, hop: int) -> np.ndarray:
    """Onset strength with a short window so peaks sit within a few ms of the attack."""
    import librosa

    return librosa.onset.onset_strength(y=y, sr=sr, hop_length=hop, n_fft=512)
```

```python
"""ffmpeg and ffprobe wrappers. Arguments are always lists; nothing goes through a shell."""
from __future__ import annotations

import json
import subprocess
from pathlib import Path

from core.pipeline import Fatal


def ffmpeg(args: list[str]) -> None:
    r = subprocess.run(
        ["ffmpeg", "-hide_banner", "-loglevel", "error", "-y", *args],
        capture_output=True,
        text=True,
    )
    if r.returncode != 0:
        raise Fatal(f"ffmpeg failed: {r.stderr.strip()[-300:]}")


def probe(path: Path) -> dict:
    r = subprocess.run(
        ["ffprobe", "-v", "error", "-print_format", "json", "-show_streams", "-show_format", str(path)],
        capture_output=True,
        text=True,
    )
    if r.returncode != 0:
        raise Fatal(f"ffprobe could not read {Path(path).name}")
    info = json.loads(r.stdout)
    streams = info.get("streams", [])
    audio = [s for s in streams if s.get("codec_type") == "audio"]
    video = [
        s
        for s in streams
        if s.get("codec_type") == "video" and not s.get("disposition", {}).get("attached_pic", 0)
    ]
    if not audio:
        raise Fatal(f"{Path(path).name} has no audio stream")
    fps = None
    if video:
        num, _, den = video[0].get("avg_frame_rate", "0/1").partition("/")
        if float(den or 0):
            fps = round(float(num) / float(den), 3)
    return {
        "duration": float(info.get("format", {}).get("duration", 0.0)),
        "channels": int(audio[0].get("channels", 2)),
        "has_video": bool(video),
        "video_fps": fps,
    }
```

```python
from __future__ import annotations

import os
from pathlib import Path


def config_dir() -> Path:
    return Path(os.environ.get("LISTEN_CONFIG", Path.home() / ".config" / "listen"))


def load_env(path: Path | None = None) -> None:
    p = path or config_dir() / ".env"
    if not p.exists():
        return
    for line in p.read_text().splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        k, v = line.split("=", 1)
        os.environ.setdefault(k.strip(), v.strip().strip('"').strip("'"))
```

```python
"""Synthetic audio with known ground truth. Every generator is deterministic."""
from __future__ import annotations

import numpy as np
import soundfile as sf
from scipy.signal import butter, sosfilt

SR = 44100


def write(path, y, sr: int = SR) -> None:
    sf.write(str(path), np.asarray(y, dtype=np.float32), sr, subtype="FLOAT")


def bandpass(x, lo, hi, sr=SR):
    return sosfilt(butter(4, [lo, hi], btype="band", fs=sr, output="sos"), x)


def highpass(x, f, sr=SR):
    return sosfilt(butter(4, f, btype="high", fs=sr, output="sos"), x)


def lowpass(x, f, sr=SR):
    return sosfilt(butter(4, f, btype="low", fs=sr, output="sos"), x)


def _env(n, decay_s, sr=SR):
    return np.exp(-np.arange(n) / (decay_s * sr))


def kick(sr=SR):
    n = int(0.25 * sr)
    t = np.arange(n) / sr
    freq = 50 + 70 * np.exp(-t * 30)
    return np.sin(2 * np.pi * np.cumsum(freq) / sr) * _env(n, 0.08, sr)


def snare(sr=SR):
    rng = np.random.default_rng(1)
    n = int(0.18 * sr)
    noise = bandpass(rng.standard_normal(n), 300, 4000, sr)
    tone = np.sin(2 * np.pi * 180 * np.arange(n) / sr)
    return (0.7 * noise / np.max(np.abs(noise)) + 0.3 * tone) * _env(n, 0.05, sr)


def hat(sr=SR):
    rng = np.random.default_rng(2)
    n = int(0.05 * sr)
    x = highpass(rng.standard_normal(n), 7000, sr)
    return 0.4 * x / np.max(np.abs(x)) * _env(n, 0.012, sr)


def _add(y, x, t, sr, gain):
    i = int(round(t * sr))
    j = min(len(y), i + len(x))
    if i < len(y):
        y[i:j] += gain * x[: j - i]


def drum_loop(bpm=120.0, bars=16, sr=SR, jitter=0.0, seed=0):
    """4/4 loop starting at 0.5 s: kick on 1 and 3, snare on 2 and 4, hats on eighths.

    Returns (signal, truth). truth holds beats, downbeats, kicks, snares, hats (seconds) and duration.
    """
    rng = np.random.default_rng(seed)
    beat = 60.0 / bpm
    n_beats = bars * 4
    ibis = beat * (1 + jitter * rng.uniform(-1, 1, n_beats))
    beats = np.concatenate([[0.5], 0.5 + np.cumsum(ibis[:-1])])
    y = np.zeros(int((beats[-1] + beat + 1.0) * sr))
    k, s, h = kick(sr), snare(sr), hat(sr)
    kicks, snares, hats = [], [], []
    for i, b in enumerate(beats):
        pos = i % 4
        if pos in (0, 2):
            _add(y, k, b, sr, 1.0 if pos == 0 else 0.85)
            kicks.append(b)
        else:
            _add(y, s, b, sr, 0.8)
            snares.append(b)
        _add(y, h, b, sr, 0.5)
        hats.append(b)
        off = b + ibis[i] / 2
        _add(y, h, off, sr, 0.35)
        hats.append(off)
    y = 0.8 * y / np.max(np.abs(y))
    truth = {
        "beats": beats,
        "downbeats": beats[::4],
        "kicks": np.array(kicks),
        "snares": np.array(snares),
        "hats": np.array(hats),
        "duration": len(y) / sr,
    }
    return y.astype(np.float32), truth


def pink_noise(seconds, sr=SR, seed=0):
    rng = np.random.default_rng(seed)
    n = int(seconds * sr)
    spec = np.fft.rfft(rng.standard_normal(n))
    f = np.fft.rfftfreq(n, 1 / sr)
    f[0] = f[1]
    x = np.fft.irfft(spec / np.sqrt(f), n)
    return (0.5 * x / np.max(np.abs(x))).astype(np.float32)


def to_lufs(y, target, sr=SR):
    import pyloudnorm as pyln

    meter = pyln.Meter(sr)
    return pyln.normalize.loudness(y, meter.integrated_loudness(y), target).astype(np.float32)


def midi_hz(n):
    return 440.0 * 2 ** ((n - 69) / 12)


def chords(progression, seconds_each=2.0, repeats=2, sr=SR):
    out = []
    n = int(seconds_each * sr)
    t = np.arange(n) / sr
    fade = np.minimum(1, np.minimum(t / 0.02, (seconds_each - t) / 0.05))
    for notes in progression:
        x = sum(np.sin(2 * np.pi * midi_hz(m) * h * t) / h for m in notes for h in (1, 2, 3))
        out.append(x * fade)
    y = np.concatenate(out * repeats)
    return (0.5 * y / np.max(np.abs(y))).astype(np.float32)


def drop_track(sr=SR, gain=0.8):
    """Filtered quiet intro, then a full drop with sub bass at downbeat 10 (20.5 s)."""
    loop, truth = drum_loop(120, bars=20, sr=sr)
    drop_t = float(truth["downbeats"][10])
    i = int(round(drop_t * sr))
    y = loop.astype(float).copy()
    y[:i] = lowpass(y[:i], 400, sr) * 0.15
    y[i:] += 0.6 * np.sin(2 * np.pi * 50 * np.arange(len(y) - i) / sr)
    y = gain * y / np.max(np.abs(y))
    return y.astype(np.float32), {**truth, "drop": drop_t}


def riser_track(sr=SR):
    """Quiet bed 0 to 20 s, linear high riser 12 to 20 s, loud drums from 20 s."""
    bed = 0.03 * pink_noise(28, sr, seed=3)
    y = bed.astype(float)
    a, b = int(12 * sr), int(20 * sr)
    rng = np.random.default_rng(4)
    noise = highpass(rng.standard_normal(b - a), 4000, sr)
    noise /= np.max(np.abs(noise))
    y[a:b] += noise * np.linspace(0.02, 0.8, b - a)
    loop, _ = drum_loop(120, bars=4, sr=sr)
    j = int(20 * sr)
    seg = loop[: len(y) - j]
    y[j : j + len(seg)] += seg
    y = 0.8 * y / np.max(np.abs(y))
    return y.astype(np.float32), {"riser_start": 12.0, "riser_end": 20.0, "drop": 20.0}


def impacts_track(sr=SR, times=(2.0, 5.5, 9.0)):
    y = 0.03 * pink_noise(12, sr, seed=5).astype(float)
    rng = np.random.default_rng(6)
    for t in times:
        burst = rng.standard_normal(int(0.3 * sr)) * _env(int(0.3 * sr), 0.06, sr)
        _add(y, burst / np.max(np.abs(burst)), t, sr, 0.9)
        _add(y, kick(sr), t, sr, 0.9)
    y = 0.8 * y / np.max(np.abs(y))
    return y.astype(np.float32), {"impacts": list(times)}


def syllables(seconds=8.0, rate_hz=4.0, sr=SR, seed=7):
    """Speech-like signal: voiced harmonic tone with gliding pitch, amplitude-modulated at syllable rate."""
    rng = np.random.default_rng(seed)
    t = np.arange(int(seconds * sr)) / sr
    pitch = 140 + 30 * np.sin(2 * np.pi * 0.7 * t) + 10 * rng.standard_normal()
    phase = 2 * np.pi * np.cumsum(pitch) / sr
    voiced = sum(np.sin(h * phase) / h for h in range(1, 12))
    voiced = bandpass(voiced, 300, 3400, sr)
    am = np.clip(np.sin(2 * np.pi * rate_hz * t), 0, None) ** 2
    y = voiced * am
    return (0.6 * y / np.max(np.abs(y))).astype(np.float32)
```

```python
"""Stage 0: decode any input (file, URL, video) into the two WAVs every other stage reads."""
from __future__ import annotations

import subprocess
from pathlib import Path

import numpy as np
import soundfile as sf

from core.context import Context
from core.media import ffmpeg, probe
from core.pipeline import Fatal

VERSION = 1
DEPS: tuple[str, ...] = ()
SR = 44100
SPEECH_SR = 16000
LONG_INPUT_S = 20 * 60
SHORT_INPUT_S = 3.0


def resolve_source(src: str, downloads: Path) -> Path:
    """Return a local file for src, downloading URLs with yt-dlp."""
    if src.startswith(("http://", "https://")):
        downloads.mkdir(parents=True, exist_ok=True)
        r = subprocess.run(
            ["yt-dlp", "-x", "--audio-format", "wav", "--no-playlist",
             "-o", str(downloads / "%(id)s.%(ext)s"), "--print", "after_move:filepath", src],
            capture_output=True,
            text=True,
        )
        if r.returncode != 0 or not r.stdout.strip():
            raise Fatal(f"download failed: {r.stderr.strip()[-300:]}")
        return Path(r.stdout.strip().splitlines()[-1])
    p = Path(src).expanduser()
    if not p.exists():
        raise Fatal(f"no such file: {p}")
    return p.resolve()


def run(ctx: Context) -> dict:
    src = Path(ctx.options["source"])
    meta = probe(src)
    trim: list[str] = []
    if ctx.options.get("start") is not None:
        trim += ["-ss", str(ctx.options["start"])]
    if ctx.options.get("end") is not None:
        trim += ["-to", str(ctx.options["end"])]
    master, speech = ctx.path("master.wav"), ctx.path("speech.wav")
    ffmpeg(["-i", str(src), *trim, "-map", "0:a:0", "-ac", "2", "-ar", str(SR), "-c:a", "pcm_f32le", str(master)])
    ffmpeg(["-i", str(master), "-ac", "1", "-ar", str(SPEECH_SR), "-c:a", "pcm_s16le", str(speech)])
    info = sf.info(str(master))
    duration = info.frames / info.samplerate
    if duration < 0.05:
        raise Fatal("the selected range contains no audio")
    y, _ = sf.read(str(speech), dtype="float32")
    silent = bool(y.size == 0 or np.max(np.abs(y)) < 1e-4)
    warnings = []
    if duration > LONG_INPUT_S:
        warnings.append("input is over 20 minutes; consider --start/--end")
    return {
        "source": str(src),
        "file": src.name,
        "duration": round(duration, 3),
        "sr": SR,
        "short": duration < SHORT_INPUT_S,
        "silent": silent,
        "warnings": warnings,
        "has_video": meta["has_video"],
        "video_fps": meta["video_fps"],
    }
```

```python
"""Stage 2: beats, downbeats, tempo and meter, refined to the nearest onset peak."""
from __future__ import annotations

from collections import Counter

import numpy as np

from core.audio import ANALYSIS_SR, load_mono, onset_env
from core.context import Context

VERSION = 1
DEPS = ("ingest",)
REFINE_HOP = 128


def _librosa_beats(path) -> tuple[np.ndarray, np.ndarray]:
    import librosa

    y = load_mono(path)
    _, frames = librosa.beat.beat_track(y=y, sr=ANALYSIS_SR, units="frames")
    beats = librosa.frames_to_time(frames, sr=ANALYSIS_SR)
    return beats, beats[::4]


def detect(path) -> tuple[np.ndarray, np.ndarray, str]:
    try:
        from beat_this.inference import File2Beats
    except ImportError:
        beats, downs = _librosa_beats(path)
        return beats, downs, "librosa"
    f2b = File2Beats(checkpoint_path="final0", device="cpu", dbn=False)
    beats, downbeats = f2b(str(path))
    return np.asarray(beats, dtype=float), np.asarray(downbeats, dtype=float), "beat_this"


def refine(beats: np.ndarray, env: np.ndarray, times: np.ndarray, window: float = 0.03) -> np.ndarray:
    """Move each beat to the strongest onset within +/- window, when that onset is clearly a peak."""
    out = np.asarray(beats, dtype=float).copy()
    floor = 1.5 * float(np.median(env)) + 1e-9
    for i, b in enumerate(out):
        lo, hi = np.searchsorted(times, [b - window, b + window])
        if hi - lo < 2:
            continue
        seg = env[lo:hi]
        if seg.max() >= floor:
            out[i] = times[lo + int(seg.argmax())]
    return out


def number_beats(beats, downbeats, tol: float = 0.035) -> list[tuple[int, int]]:
    db = np.sort(np.asarray(downbeats, dtype=float))
    out, bar, pos = [], 0, 0
    for t in beats:
        j = int(np.searchsorted(db, t))
        near = any(0 <= k < len(db) and abs(db[k] - t) < tol for k in (j - 1, j))
        if near:
            bar, pos = bar + 1, 1
        else:
            pos += 1
        out.append((bar, pos))
    return out


def meter(numbered: list[tuple[int, int]]) -> str:
    per_bar: dict[int, int] = {}
    for bar, pos in numbered:
        if bar >= 1:
            per_bar[bar] = max(per_bar.get(bar, 0), pos)
    complete = [n for b, n in per_bar.items() if b != max(per_bar, default=0)]
    if not complete:
        return "unknown"
    return f"{Counter(complete).most_common(1)[0][0]}/4"


def confidence(beats) -> float:
    beats = np.asarray(beats, dtype=float)
    if beats.size < 8:
        return 0.0
    ibi = np.diff(beats)
    cv = float(np.std(ibi) / np.mean(ibi))
    return float(np.clip(1 - 4 * cv, 0, 1))


def tempo_changes(beats, bpm: float, window: int = 8, threshold: float = 0.04) -> list[dict]:
    beats = np.asarray(beats, dtype=float)
    if beats.size < window * 2 or bpm <= 0:
        return []
    ibi = np.diff(beats)
    changes, current = [], bpm
    for i in range(len(ibi) - window + 1):
        local = 60.0 / float(np.median(ibi[i : i + window]))
        if abs(local - current) / current > threshold:
            changes.append({"t": round(float(beats[i]), 3), "bpm": round(local, 1)})
            current = local
    return changes


def run(ctx: Context) -> dict:
    import librosa

    path = ctx.path("master.wav")
    beats, downbeats, source = detect(path)
    y = load_mono(path)
    env = onset_env(y, ANALYSIS_SR, REFINE_HOP)
    times = librosa.times_like(env, sr=ANALYSIS_SR, hop_length=REFINE_HOP)
    beats = refine(beats, env, times)
    if beats.size and downbeats.size:
        downbeats = np.array([beats[np.argmin(np.abs(beats - d))] for d in downbeats])
    numbered = number_beats(beats, downbeats)
    peak = float(np.percentile(env, 99)) or 1.0
    idx = np.clip(np.searchsorted(times, beats), 0, len(env) - 1)
    strengths = np.clip(env[idx] / peak, 0, 1)
    bpm = 60.0 / float(np.median(np.diff(beats))) if beats.size > 1 else 0.0
    conf = confidence(beats)
    return {
        "source": source,
        "bpm": round(bpm, 2),
        "confidence": round(conf, 3),
        "low_confidence": conf < 0.5,
        "meter": meter(numbered),
        "changes": tempo_changes(beats, bpm),
        "beats": [
            {"t": round(float(t), 4), "bar": b, "beat": p, "strength": round(float(s), 3)}
            for t, (b, p), s in zip(beats, numbered, strengths)
        ],
        "downbeats": [round(float(d), 4) for d in downbeats],
    }
```

```python
"""Per-instrument hits: kick, snare and hat from the drums stem (or the mix), bass hits and vocal entries."""
from __future__ import annotations

import numpy as np

from core.audio import ANALYSIS_SR, load_mono
from core.context import Context

VERSION = 1
DEPS = ("ingest", "stems")
HOP = 128
N_FFT = 1024
# Snare band stops at 3 kHz so hat leakage (hats sit above 5 kHz) stays under the gate.
DRUM_BANDS = {"kick": (20, 120), "snare": (250, 3000), "hat": (5000, 12000)}
BASS_BAND = (20, 400)
GATE = 1e-3  # ignore onsets where the band is more than 30 dB below its loudest frame


def band_onsets(y: np.ndarray, sr: int, lo: float, hi: float) -> list[dict]:
    import librosa

    S = np.abs(librosa.stft(y, n_fft=N_FFT, hop_length=HOP)) ** 2
    freqs = librosa.fft_frequencies(sr=sr, n_fft=N_FFT)
    band = S[(freqs >= lo) & (freqs < hi)]
    if band.size == 0:
        return []
    level = band.sum(axis=0)
    if level.max() <= 0:
        return []
    env = librosa.onset.onset_strength(S=librosa.power_to_db(band + 1e-10), sr=sr, hop_length=HOP)
    frames = librosa.onset.onset_detect(
        onset_envelope=env, sr=sr, hop_length=HOP, units="frames", delta=0.1, wait=int(0.06 * sr / HOP)
    )
    frames = [f for f in frames if level[min(f + 1, len(level) - 1)] >= GATE * level.max()]
    if not frames:
        return []
    peak = float(np.percentile(env[frames], 95)) or 1.0
    return [
        {
            "t": round(float(librosa.frames_to_time(f, sr=sr, hop_length=HOP)), 4),
            "v": round(float(min(1.0, env[f] / peak)), 3),
        }
        for f in frames
    ]


def vocal_entries(y: np.ndarray, sr: int, gap_s: float = 0.3) -> list[dict]:
    import librosa

    rms = librosa.feature.rms(y=y, frame_length=1024, hop_length=HOP)[0]
    if rms.size == 0 or rms.max() <= 0:
        return []
    ref = float(np.percentile(rms, 99))
    on = rms > 0.1 * ref
    frame_s = HOP / sr
    entries, off_run = [], gap_s
    for i, active in enumerate(on):
        if active and off_run >= gap_s:
            entries.append({"t": round(i * frame_s, 4), "v": round(float(min(1.0, rms[i] / ref)), 3)})
        off_run = 0.0 if active else off_run + frame_s
    return entries


def run(ctx: Context) -> dict:
    stems = ctx.data("stems")
    if stems:
        drums = load_mono(ctx.path(stems["stems"]["drums"]))
    else:
        drums = load_mono(ctx.path("master.wav"))
    result = {name: band_onsets(drums, ANALYSIS_SR, lo, hi) for name, (lo, hi) in DRUM_BANDS.items()}
    if stems:
        result["bass"] = band_onsets(load_mono(ctx.path(stems["stems"]["bass"])), ANALYSIS_SR, *BASS_BAND)
        result["vocal"] = vocal_entries(load_mono(ctx.path(stems["stems"]["vocals"])), ANALYSIS_SR)
    else:
        result["bass"], result["vocal"] = [], []
    return {"from": "stems" if stems else "mix", "hits": result}
```

```python
"""Labels the input as music, speech, sfx or mixed so later stages and the report focus correctly."""
from __future__ import annotations

import numpy as np
from scipy.signal import butter, sosfilt

from core.audio import ANALYSIS_SR, CURVE_HOP, CURVE_HZ, load_mono
from core.context import Context

VERSION = 1
DEPS = ("ingest", "stems", "rhythm")
RHYTHMIC_CONF = 0.6
SPEECH_MOD = 0.45
HARMONIC = 0.6


def speech_modulation(y: np.ndarray, sr: int) -> float:
    """Share of the 300 to 3400 Hz envelope's modulation energy at syllable rates (2 to 8 Hz)."""
    import librosa

    band = sosfilt(butter(4, [300, 3400], btype="band", fs=sr, output="sos"), y)
    env = librosa.feature.rms(y=band, frame_length=2 * CURVE_HOP, hop_length=CURVE_HOP)[0]
    env = env - env.mean()
    if not np.any(env):
        return 0.0
    spec = np.abs(np.fft.rfft(env * np.hanning(len(env)))) ** 2
    f = np.fft.rfftfreq(len(env), 1 / CURVE_HZ)
    total = spec[(f >= 0.5) & (f <= 20)].sum()
    return float(spec[(f >= 2) & (f <= 8)].sum() / total) if total > 0 else 0.0


def harmonic_ratio(y: np.ndarray, sr: int, max_s: float = 60.0) -> float:
    import librosa

    S = np.abs(librosa.stft(y[: int(max_s * sr)])) ** 2
    H, P = librosa.decompose.hpss(S)
    total = H.sum() + P.sum()
    return float(H.sum() / total) if total > 0 else 0.0


def classify(beat_conf: float, vocal_ratio: float | None, speech_mod: float, harmonic: float, has_video: bool) -> str:
    if beat_conf >= RHYTHMIC_CONF:
        if vocal_ratio is not None and vocal_ratio >= 0.15 and has_video:
            return "mixed"
        return "music"
    if vocal_ratio is not None:
        if vocal_ratio >= 0.5 or (vocal_ratio >= 0.25 and speech_mod >= SPEECH_MOD):
            return "speech"
    elif speech_mod >= SPEECH_MOD:
        return "speech"
    return "music" if harmonic >= HARMONIC else "sfx"


def _vocal_ratio(ctx: Context, stems: dict) -> float:
    energy = {}
    for name, fname in stems["stems"].items():
        y = load_mono(ctx.path(fname))
        energy[name] = float(np.sum(y.astype(float) ** 2))
    total = sum(energy.values())
    return energy.get("vocals", 0.0) / total if total > 0 else 0.0


def run(ctx: Context) -> dict:
    ingest = ctx.data("ingest") or {}
    rhythm = ctx.data("rhythm")
    stems = ctx.data("stems")
    y = load_mono(ctx.path("master.wav"))
    beat_conf = float(rhythm["confidence"]) if rhythm else 0.0
    vocal_ratio = _vocal_ratio(ctx, stems) if stems else None
    mod = speech_modulation(y, ANALYSIS_SR)
    harm = harmonic_ratio(y, ANALYSIS_SR)
    kind = classify(beat_conf, vocal_ratio, mod, harm, bool(ingest.get("has_video")))
    return {
        "kind": kind,
        "features": {
            "beat_conf": round(beat_conf, 3),
            "vocal_ratio": None if vocal_ratio is None else round(vocal_ratio, 3),
            "speech_mod": round(mod, 3),
            "harmonic": round(harm, 3),
        },
    }
```

```python
from core.context import Context

DEPS = ("ingest", "rhythm", "stems", "classify")
CURVES_FILE = "curves_structure.npz"
SECTION_TARGET_S = 20
MIN_SECTION_S = 4.0
BANDS = {"low": (20, 250), "mid": (250, 4000), "high": (4000, 12000)}

NOTES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]

def _fit(x: np.ndarray, n: int) -> np.ndarray:
    return x[:n] if len(x) >= n else np.pad(x, (0, n - len(x)))


def energy_curves(y: np.ndarray, sr: int) -> dict[str, np.ndarray]:
    import librosa

    rms = librosa.feature.rms(y=y, frame_length=2 * CURVE_HOP, hop_length=CURVE_HOP)[0]

    out = {"rms": rms, "energy": norm01(rms, floor=0.0)}
    for name, (lo, hi) in BANDS.items():
        out[name] = norm01(np.sqrt(S[(freqs >= lo) & (freqs < hi)].sum(axis=0)), floor=0.0)
    n = min(len(v) for v in out.values())
    return {k: v[:n] for k, v in out.items()}


def _z(x: np.ndarray) -> np.ndarray:
    return (x - x.mean(axis=1, keepdims=True)) / (x.std(axis=1, keepdims=True) + 1e-9)


def _merge_short(starts: list[float], duration: float) -> list[float]:
    out = [0.0]
    for s in starts[1:]:
        if s - out[-1] >= MIN_SECTION_S:
            out.append(s)
    if len(out) > 1 and duration - out[-1] < MIN_SECTION_S:
        out.pop()
    return out


def find_sections(y, sr, downbeats, duration: float, k: int | None = None) -> list[tuple[float, float]]:
    import librosa

    hop = 512
    chroma = librosa.feature.chroma_cqt(y=y, sr=sr, hop_length=hop)
    mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13, hop_length=hop)
    rms = librosa.feature.rms(y=y, hop_length=hop)
    n = min(chroma.shape[1], mfcc.shape[1], rms.shape[1])
    feat = np.vstack([_z(chroma[:, :n]), _z(mfcc[:, :n]), 2 * _z(rms[:, :n])])
    grid = np.asarray(downbeats, dtype=float) if len(downbeats) >= 4 else np.arange(1.0, duration, 1.0)
    frames = librosa.time_to_frames(grid, sr=sr, hop_length=hop)
    bounds = librosa.util.fix_frames(frames[frames < n], x_min=0, x_max=n, pad=True)
    synced = librosa.util.sync(feat, bounds, aggregate=np.median, pad=False)
    seg_starts = librosa.frames_to_time(bounds[:-1], sr=sr, hop_length=hop)
    k = k or int(np.clip(round(duration / SECTION_TARGET_S), 2, 10))
    k = max(1, min(k, synced.shape[1]))
    idx = librosa.segment.agglomerative(synced, k)
    starts = _merge_short(sorted({round(float(seg_starts[i]), 3) for i in idx} | {0.0}), duration)
    ends = starts[1:] + [round(float(duration), 3)]
    return list(zip(starts, ends))


def auto_labels(energies: list[float]) -> list[str]:
    if not energies:
        return []
    hi = max(energies) or 1.0
    n = len(energies)
    labels = []
    for i, e in enumerate(energies):
        if n > 1 and i == 0 and e < 0.6 * hi:
            labels.append("intro")
        elif n > 2 and i == n - 1 and e < 0.6 * hi:
            labels.append("outro")
        elif e >= 0.8 * hi:
            labels.append("peak")
        elif i + 1 < n and energies[i + 1] >= 0.8 * hi and e < energies[i + 1]:
            labels.append("build")
        else:
            labels.append("body")
    return labels


def estimate_key(y: np.ndarray, sr: int) -> dict:
    import librosa

    chroma = librosa.feature.chroma_cqt(y=y, sr=sr).mean(axis=1)
    scores = []
    for mode, profile in (("major", MAJOR), ("minor", MINOR)):
        for i in range(12):
            r = float(np.corrcoef(chroma, np.roll(profile, i))[0, 1])
            scores.append((r, NOTES[i], mode))
    scores.sort(reverse=True)
    best = scores[0]
    return {"tonic": best[1], "mode": best[2], "confidence": round(float(np.clip(best[0], 0, 1)), 3)}


def run(ctx: Context) -> dict:
    import librosa

    ingest = ctx.data("ingest")
    rhythm = ctx.data("rhythm") or {}
    stems = ctx.data("stems")
    kind = (ctx.data("classify") or {}).get("kind", "music")
    duration = float(ingest["duration"])
    y = load_mono(ctx.path("master.wav"))
    curves = energy_curves(y, ANALYSIS_SR)
    n = len(curves["energy"])
    if stems:
        for name, fname in stems["stems"].items():
            ys = load_mono(ctx.path(fname))
            r = librosa.feature.rms(y=ys, frame_length=2 * CURVE_HOP, hop_length=CURVE_HOP)[0]
            curves[f"stem_{name}"] = _fit(norm01(r, floor=0.0), n)
    np.savez_compressed(ctx.path(CURVES_FILE), **curves)
    spans = find_sections(y, ANALYSIS_SR, rhythm.get("downbeats", []), duration)
    energies = []
    for a, b in spans:
        i, j = int(a * CURVE_HZ), max(int(a * CURVE_HZ) + 1, int(b * CURVE_HZ))
        energies.append(float(curves["energy"][i:j].mean()))
    labels = auto_labels(energies)
    sections = [
        {"id": f"s{i + 1}", "label": lab, "start": a, "end": b, "energy": round(e, 3)}
        for i, ((a, b), e, lab) in enumerate(zip(spans, energies, labels))
    ]
    key = estimate_key(y, ANALYSIS_SR) if kind in ("music", "mixed") else None
    return {"curves_file": CURVES_FILE, "curve_hz": CURVE_HZ, "sections": sections, "key": key}
```

```python
"""Stage 3b: drops, impacts, risers, silences, vocal entries, cut and hold points.

Every threshold is relative to the track itself, so quiet masters behave like loud ones.
"""
from __future__ import annotations

import numpy as np
from scipy.signal import find_peaks

from core.audio import ANALYSIS_SR, CURVE_HOP, load_mono, onset_env
from core.context import Context
from core.pipeline import StageUnavailable

VERSION = 1
DEPS = ("ingest", "rhythm", "structure", "hits", "classify")
SILENCE_REL_DB = -50.0
SILENCE_MIN_S = 0.05
DROP_JUMP = 0.25
DROP_MIN_AFTER = 0.4
DROP_LOW_JUMP = 0.2
WIN_S = 2.0


def _smooth(x: np.ndarray, n: int) -> np.ndarray:
    if n <= 1:
        return np.asarray(x, dtype=float)
    return np.convolve(x, np.ones(n) / n, mode="same")


def _runs(mask: np.ndarray) -> list[tuple[int, int]]:
    d = np.diff(np.concatenate([[0], mask.astype(np.int8), [0]]))
    return list(zip(np.where(d == 1)[0], np.where(d == -1)[0]))


def _dedupe(events: list[dict], min_gap: float) -> list[dict]:
    kept: list[dict] = []
    for e in sorted(events, key=lambda e: -e["strength"]):
        if all(abs(e["t"] - k["t"]) >= min_gap for k in kept):
            kept.append(e)
    return sorted(kept, key=lambda e: e["t"])


def _window_means(x: np.ndarray, w: int) -> tuple[np.ndarray, np.ndarray]:
    """Mean of the w samples before and after each index (NaN where the window falls off the edge)."""
    c = np.concatenate([[0.0], np.cumsum(x)])
    n = len(x)
    idx = np.arange(n)
    before = np.full(n, np.nan)
    after = np.full(n, np.nan)
    ok_b = idx >= w
    ok_a = idx + w <= n
    before[ok_b] = (c[idx[ok_b]] - c[idx[ok_b] - w]) / w
    after[ok_a] = (c[idx[ok_a] + w] - c[idx[ok_a]]) / w
    return before, after


def detect_silences(rms: np.ndarray, hz: int, min_s: float = SILENCE_MIN_S) -> list[dict]:
    db = 20 * np.log10(np.maximum(rms, 1e-10))
    ref = float(np.percentile(db, 95))
    quiet = db < ref + SILENCE_REL_DB
    out = []
    for a, b in _runs(quiet):
        if (b - a) / hz >= min_s:
            out.append({"t": round(a / hz, 3), "end": round(b / hz, 3), "type": "silence",
                        "strength": round(min(1.0, (b - a) / hz), 3)})
    return out


def detect_drops(energy, low, hz: int, candidates, win_s: float = WIN_S) -> list[dict]:
    w = int(win_s * hz)
    out = []
    for t in candidates:
        i = int(round(t * hz))
        if i - w < 0 or i + w > len(energy):
            continue
        jump = energy[i : i + w].mean() - energy[i - w : i].mean()
        low_jump = low[i : i + w].mean() - low[i - w : i].mean()
        if jump >= DROP_JUMP and energy[i : i + w].mean() >= DROP_MIN_AFTER and low_jump >= DROP_LOW_JUMP:
            out.append({"t": round(float(t), 4), "type": "drop", "strength": round(float(min(1.0, 2 * jump)), 3)})
    return _dedupe(out, 4.0)


def step_candidates(energy: np.ndarray, hz: int, win_s: float = 0.5) -> list[float]:
    before, after = _window_means(np.asarray(energy, dtype=float), int(win_s * hz))
    diff = np.nan_to_num(after - before)
    peaks, _ = find_peaks(diff, height=0.2, distance=max(1, 2 * hz))
    return [round(p / hz, 3) for p in peaks]


def detect_impacts(env: np.ndarray, hz: int, exclude, top: int = 30, min_gap: float = 1.0) -> list[dict]:
    if env.size == 0 or env.max() <= 0:
        return []
    thr = max(float(np.percentile(env, 98)), 3 * float(np.median(env)) + 1e-9)
    peaks, _ = find_peaks(env, height=thr, distance=max(1, int(min_gap * hz)))
    if peaks.size == 0:
        return []
    top_val = float(env[peaks].max())
    events = [
        {"t": round(p / hz, 4), "type": "impact", "strength": round(float(env[p] / top_val), 3)}
        for p in peaks
        if all(abs(p / hz - x) > 0.2 for x in exclude)
    ]
    return sorted(sorted(events, key=lambda e: -e["strength"])[:top], key=lambda e: e["t"])


def detect_risers(high: np.ndarray, hz: int, targets, min_s=2.0, max_s=16.0, min_rise=0.15, min_corr=0.85) -> list[dict]:
    """Best window scores rise * correlation: inside a ramp the rise grows with length, and once the
    window reaches back past the ramp's start the rise stops growing while correlation falls."""
    smooth = _smooth(high, int(0.25 * hz))
    half = int(0.5 * hz)
    unique = []
    for t in sorted(targets):
        if all(abs(t - u) > 0.5 for u in unique):
            unique.append(t)
    out = []
    for t in unique:
        end = int(round(t * hz)) - 1
        best = None
        for length in np.arange(min_s, max_s + 1e-9, 0.5):
            start = end - int(length * hz)
            if start < 0:
                break
            seg = smooth[start:end]
            rise = seg[-half:].mean() - seg[:half].mean()
            if rise < min_rise or np.std(seg) == 0:
                continue
            corr = float(np.corrcoef(np.arange(len(seg)), seg)[0, 1])
            if corr >= min_corr and (best is None or rise * corr > best[2]):
                best = (start, rise, rise * corr)
        if best:
            out.append({"t": round(best[0] / hz, 3), "end": round(float(t), 3), "type": "riser",
                        "strength": round(float(min(1.0, best[1])), 3)})
    return out


def detect_vocal_changes(curve: np.ndarray, hz: int, on: float = 0.15, min_gap_s: float = 2.0) -> list[dict]:
    active = _smooth(curve, int(0.3 * hz)) > on
    merged: list[tuple[int, int]] = []
    for a, b in _runs(active):
        if merged and (a - merged[-1][1]) / hz < min_gap_s:
            merged[-1] = (merged[-1][0], b)
        else:
            merged.append((a, b))
    events = []
    for a, b in merged:
        if (b - a) / hz < 0.5:
            continue
        events.append({"t": round(a / hz, 3), "type": "vocal_in", "strength": 1.0})
        events.append({"t": round(b / hz, 3), "type": "vocal_out", "strength": 1.0})
    return events


def rank_cuts(downbeats, section_starts, energy: np.ndarray, hz: int, duration: float) -> list[dict]:
    downbeats = list(downbeats)
    if not downbeats:
        return []
    scored = []
    for i, t in enumerate(downbeats):
        phrase = 1.0 if i % 4 == 0 else 0.0
        boundary = 1.0 if any(abs(t - s) < 0.15 for s in section_starts) else 0.0
        j, w = int(t * hz), int(hz)
        change = abs(energy[j : j + w].mean() - energy[j - w : j].mean()) if j >= w and j + w <= len(energy) else 0.0
        score = 0.4 * phrase + 0.4 * boundary + 0.2 * min(1.0, 4 * change)
        scored.append({"t": round(float(t), 4), "type": "cut", "strength": round(score, 3)})
    limit = max(4, int(duration / 15))
    min_gap = 2 * (downbeats[1] - downbeats[0]) if len(downbeats) > 1 else 4.0
    kept: list[dict] = []
    for e in sorted(scored, key=lambda e: (-e["strength"], e["t"])):
        if len(kept) >= limit:
            break
        if all(abs(e["t"] - k["t"]) >= min_gap - 1e-6 for k in kept):
            kept.append(e)
    return sorted(kept, key=lambda e: e["t"])


def detect_holds(sections, energy: np.ndarray, hz: int, busy_times, min_s=4.0, max_std=0.06) -> list[dict]:
    out = []
    for s in sections:
        a, b = s["start"], s["end"]
        if b - a < min_s:
            continue
        seg = energy[int(a * hz) : int(b * hz)]
        if seg.size and seg.std() < max_std and not any(a < t < b for t in busy_times):
            out.append({"t": a, "end": b, "type": "hold", "strength": round(float(1 - seg.std() / max_std), 3)})
    return out


def run(ctx: Context) -> dict:
    ingest = ctx.data("ingest")
    rhythm = ctx.data("rhythm") or {}
    structure = ctx.data("structure")
    kind = (ctx.data("classify") or {}).get("kind", "music")
    if not structure:
        raise StageUnavailable("structure stage unavailable")
    c = np.load(ctx.path(structure["curves_file"]))
    hz = structure["curve_hz"]
    duration = float(ingest["duration"])
    energy, low, high, rms = c["energy"], c["low"], c["high"], c["rms"]
    downbeats = rhythm.get("downbeats", [])
    section_starts = [s["start"] for s in structure["sections"][1:]]
    candidates = sorted(set(downbeats) | set(section_starts)) if downbeats else step_candidates(energy, hz)
    drops = detect_drops(energy, low, hz, candidates)
    env = onset_env(load_mono(ctx.path("master.wav")), ANALYSIS_SR, CURVE_HOP)
    impacts = detect_impacts(env, hz, [d["t"] for d in drops], top=10 if kind == "music" else 30)
    risers = detect_risers(high, hz, [d["t"] for d in drops] + section_starts)
    silences = detect_silences(rms, hz)
    vocal = detect_vocal_changes(c["stem_vocals"], hz) if "stem_vocals" in c.files else []
    cuts = rank_cuts(downbeats, section_starts, energy, hz, duration)
    holds = detect_holds(structure["sections"], energy, hz, [e["t"] for e in drops + impacts])
    events = drops + impacts + risers + silences + vocal + cuts + holds
    return {"moments": sorted(events, key=lambda e: (e["t"], e["type"]))}
```

```python
"""Stage 4: loudness, true peak, dynamics, spectral balance, stereo image and clipping.

Band flags compare equal-width octave bands: pink noise has equal power per octave,
so a balanced mix reads roughly flat and a bump or dip shows up directly.
"""
from __future__ import annotations

from pathlib import Path

import numpy as np
import pyloudnorm as pyln
import soundfile as sf
from scipy.signal import butter, resample_poly, sosfilt, welch

from core.context import Context
from core.media import ffmpeg
from core.pipeline import Fatal

VERSION = 1
DEPS = ("ingest",)
ST_WINDOW_S = 3.0
ST_HZ = 10
OCTAVES = [31.5, 63, 125, 250, 500, 1000, 2000, 4000, 8000, 16000]


def _k_weight(y: np.ndarray, sr: int) -> np.ndarray:
    meter = pyln.Meter(sr)
    out = np.array(y, dtype=float, copy=True)
    for stage in meter._filters.values():  # pyloudnorm's BS.1770 K-weighting stages
        for ch in range(out.shape[1]):
            out[:, ch] = stage.apply_filter(out[:, ch])
    return out


def short_term(y: np.ndarray, sr: int) -> np.ndarray:
    sq = (_k_weight(y, sr) ** 2).sum(axis=1)
    c = np.concatenate([[0.0], np.cumsum(sq)])
    win = min(int(ST_WINDOW_S * sr), len(sq))
    hop = int(sr / ST_HZ)
    starts = np.arange(0, len(sq) - win + 1, hop)
    ms = (c[starts + win] - c[starts]) / win
    return -0.691 + 10 * np.log10(np.maximum(ms, 1e-12))


def loudness_range(st: np.ndarray) -> float:
    st = st[st > -70]
    if st.size < 2:
        return 0.0
    rel = 10 * np.log10(np.mean(10 ** (st / 10))) - 20
    st = st[st > rel]
    return float(np.percentile(st, 95) - np.percentile(st, 10)) if st.size > 1 else 0.0


def true_peak_db(y: np.ndarray) -> float:
    up = resample_poly(y.astype(np.float32), 4, 1, axis=0)
    return float(20 * np.log10(max(float(np.max(np.abs(up))), 1e-12)))


def clipped_samples(y: np.ndarray, thr: float = 0.999, min_run: int = 3) -> int:
    total = 0
    for ch in y.T:
        hot = np.abs(ch) >= thr
        d = np.diff(np.concatenate([[0], hot.astype(np.int8), [0]]))
        lens = np.where(d == -1)[0] - np.where(d == 1)[0]
        total += int(lens[lens >= min_run].sum())
    return total


def _band_db(f, p, lo, hi) -> float:
    return float(10 * np.log10(p[(f >= lo) & (f < hi)].sum() + 1e-20))


def measure(y: np.ndarray, sr: int) -> dict:
    y = np.asarray(y, dtype=float)
    if y.ndim == 1:
        y = np.stack([y, y], axis=1)
    integrated = float(pyln.Meter(sr).integrated_loudness(y))
    st = short_term(y, sr)
    lra = loudness_range(st)
    tp = true_peak_db(y)
    clipped = clipped_samples(y)
    mid = y.mean(axis=1)
    f, p = welch(mid, fs=sr, nperseg=8192)
    bands = {f"{c:g} Hz": round(_band_db(f, p, c / np.sqrt(2), c * np.sqrt(2)), 2) for c in OCTAVES}
    mono = bool(np.max(np.abs(y[:, 0] - y[:, 1])) < 1e-6)
    if mono:
        width, low_corr, corr = 0.0, 1.0, 1.0
    else:
        side = (y[:, 0] - y[:, 1]) / 2
        width = float(np.sqrt(np.mean(side**2)) / (np.sqrt(np.mean(mid**2)) + 1e-12))
        sos = butter(4, 120, btype="low", fs=sr, output="sos")
        lows = sosfilt(sos, y, axis=0)
        low_corr = float(np.corrcoef(lows[:, 0], lows[:, 1])[0, 1])
        corr = float(np.corrcoef(y[:, 0], y[:, 1])[0, 1])
    flags = []
    if clipped:
        flags.append(f"clipping: {clipped} samples at full scale")
    if tp > -1.0:
        flags.append(f"true peak above -1 dBTP ({tp:.1f})")
    if 0 < lra < 3:
        flags.append(f"very compressed dynamics (LRA {lra:.1f} LU)")
    mud = _band_db(f, p, 200, 400) - np.mean([_band_db(f, p, 100, 200), _band_db(f, p, 400, 800)])
    if mud > 3:
        flags.append(f"low-mid build-up 200 to 400 Hz (+{mud:.1f} dB)")
    harsh = _band_db(f, p, 2500, 5000) - np.mean([_band_db(f, p, 1250, 2500), _band_db(f, p, 5000, 10000)])
    if harsh > 3:
        flags.append(f"harsh upper mids 2.5 to 5 kHz (+{harsh:.1f} dB)")
    if _band_db(f, p, 8000, 16000) - _band_db(f, p, 1000, 2000) < -18:
        flags.append("dull top end above 8 kHz")
    if _band_db(f, p, 40, 120) - _band_db(f, p, 250, 750) < -10:
        flags.append("thin low end below 120 Hz")
    if not mono and low_corr < 0.8:
        flags.append(f"low end not mono below 120 Hz (correlation {low_corr:.2f})")
    if not mono and corr < 0:
        flags.append("phase problem: channels largely out of phase")
    return {
        "lufs": round(integrated, 2),
        "true_peak": round(tp, 2),
        "lra": round(lra, 2),
        "clipped_samples": clipped,
        "width": round(width, 3),
        "low_corr": round(low_corr, 3),
        "mono": mono,
        "bands": bands,
        "flags": flags,
        "short_term": {"hz": ST_HZ, "offset": ST_WINDOW_S / 2, "values": [round(float(v), 2) for v in st]},
    }


def _compare(own: dict, ref: dict) -> list[str]:
    deltas = []
    for band, level in own["bands"].items():
        d = (level - own["lufs"]) - (ref["bands"][band] - ref["lufs"])
        if abs(d) > 3:
            deltas.append(f"{d:+.1f} dB at {band} vs reference (loudness matched)")
    for key, unit in (("lufs", "LU"), ("lra", "LU"), ("true_peak", "dB")):
        d = own[key] - ref[key]
        if abs(d) > 1:
            deltas.append(f"{key} {d:+.1f} {unit} vs reference")
    return deltas


def _measure_ref(ctx: Context, ref_path: Path, own: dict) -> dict:
    out = ctx.path("ref.wav")
    try:
        ffmpeg(["-i", str(ref_path), "-map", "0:a:0", "-ac", "2", "-ar", "44100", "-c:a", "pcm_f32le", str(out)])
    except Fatal as e:
        return {"file": ref_path.name, "error": str(e)}
    y, sr = sf.read(str(out), dtype="float32", always_2d=True)
    ref = measure(y, sr)
    return {
        "file": ref_path.name,
        "lufs": ref["lufs"],
        "true_peak": ref["true_peak"],
        "lra": ref["lra"],
        "width": ref["width"],
        "bands": ref["bands"],
        "deltas": _compare(own, ref),
    }


def run(ctx: Context) -> dict:
    y, sr = sf.read(str(ctx.path("master.wav")), dtype="float32", always_2d=True)
    out = measure(y, sr)
    if ctx.options.get("ref"):
        out["ref"] = _measure_ref(ctx, Path(ctx.options["ref"]), out)
    return out
```

```python
"""Stage 5: word-timestamped transcript with mlx-whisper (local, Apple Silicon)."""
from __future__ import annotations

import os

from core.context import Context

VERSION = 1
DEPS = ("ingest", "stems", "classify")
DEFAULT_MODEL = "mlx-community/whisper-large-v3-turbo"
MAX_NO_SPEECH = 0.6
MIN_LOGPROB = -1.0


def clean_segments(raw: list[dict]) -> list[dict]:
    out = []
    for s in raw:
        if s.get("no_speech_prob", 0.0) > MAX_NO_SPEECH or s.get("avg_logprob", 0.0) < MIN_LOGPROB:
            continue
        text = s.get("text", "").strip()
        if not text:
            continue
        words = [
            {"t0": round(float(w["start"]), 3), "t1": round(float(w["end"]), 3), "w": w["word"].strip()}
            for w in s.get("words", [])
        ]
        out.append({"t0": round(float(s["start"]), 3), "t1": round(float(s["end"]), 3), "text": text, "words": words})
    return out


def find_pauses(segments: list[dict], min_gap: float = 0.4) -> list[dict]:
    words = [w for s in segments for w in s.get("words", [])]
    return [
        {"t": a["t1"], "end": b["t0"]}
        for a, b in zip(words, words[1:])
        if b["t0"] - a["t1"] >= min_gap
    ]


def run(ctx: Context) -> dict:
    import mlx_whisper

    stems = ctx.data("stems")
    src = ctx.path(stems["stems"]["vocals"]) if stems else ctx.path("speech.wav")
    model = os.environ.get("LISTEN_WHISPER_MODEL", DEFAULT_MODEL)
    res = mlx_whisper.transcribe(
        str(src), path_or_hf_repo=model, word_timestamps=True, condition_on_previous_text=False
    )
    segments = clean_segments(res.get("segments", []))
    return {"language": res.get("language"), "model": model, "segments": segments, "pauses": find_pauses(segments)}
```

```python
def _load() -> dict:
    try:
        return json.loads(_path().read_text())
    except (FileNotFoundError, json.JSONDecodeError):
        return {}


def _save(data: dict) -> None:
    p = _path()
    p.parent.mkdir(parents=True, exist_ok=True)
    tmp = p.with_suffix(".tmp")
    tmp.write_text(json.dumps(data))
    os.replace(tmp, p)


def cap() -> int:
    return int(os.environ.get("LISTEN_DAILY_CAP", "200"))


def today_count() -> int:
    return int(_load().get("days", {}).get(date.today().isoformat(), 0))


def check_cap() -> str | None:
    n, c = today_count(), cap()
    if n >= c:
        raise StageUnavailable(f"daily hearing cap reached ({n}/{c}); raise LISTEN_DAILY_CAP or wait until tomorrow")
    if n >= 0.8 * c:
        return f"hearing requests today: {n}/{c}"
    return None


def record() -> None:
    data = _load()
    days = data.setdefault("days", {})
    key = date.today().isoformat()
    days[key] = int(days.get(key, 0)) + 1
    _save(data)


def first_upload_notice(backend: str) -> str | None:
    if backend != "aistudio":
        return None
    data = _load()
    if data.get("notice_shown"):
        return None
    data["notice_shown"] = True
    _save(data)
    return NOTICE
```

```python
"""Gemini through a Google AI Studio API key. One structured request per call."""
from __future__ import annotations

import os
import time
from pathlib import Path

from google import genai
from google.genai import errors, types
from pydantic import BaseModel

from backends import BackendError, RateLimited

DEFAULT_MODEL = "gemini-flash-latest"


def model_name() -> str:
    return os.environ.get("LISTEN_MODEL", DEFAULT_MODEL)


def hear(audio: Path, prompt: str, schema_model: type[BaseModel], *, sleep=time.sleep, retries: int = 4) -> dict:
    key = os.environ.get("GEMINI_API_KEY")
    if not key:
        raise BackendError("GEMINI_API_KEY not set in ~/.config/listen/.env")
    client = genai.Client(api_key=key)
    part = types.Part.from_bytes(data=Path(audio).read_bytes(), mime_type="audio/ogg")
    config = types.GenerateContentConfig(
        response_mime_type="application/json", response_schema=schema_model, temperature=0.2
    )
    delay = 5.0
    for attempt in range(retries + 1):
        try:
            resp = client.models.generate_content(model=model_name(), contents=[part, prompt], config=config)
            return schema_model.model_validate_json(resp.text).model_dump()
        except errors.APIError as e:
            if e.code == 429 and attempt < retries:
                sleep(delay)
                delay = min(delay * 2, 60.0)
                continue
            if e.code == 429:
                raise RateLimited(str(e))
            raise BackendError(f"{e.code}: {e.message}")
    raise RateLimited("retries exhausted")
```

```python
"""Stage 6: a hearing model describes the sound, given the measured skeleton.

Request discipline: exactly one request per chunk, structured output, and a result
cached by prompt hash so the same audio and skeleton are never asked about twice.
Bump PROMPT_VERSION (and VERSION) whenever PROMPT changes.
"""
from __future__ import annotations

import hashlib
import os
from typing import Callable

from pydantic import BaseModel

import backends
from core import usage
from core.context import Context
from core.media import ffmpeg
from core.pipeline import Fatal, StageUnavailable

VERSION = 1
DEPS = ("ingest", "rhythm", "structure", "moments", "classify")
PROMPT_VERSION = 1
CHUNK_S = 600.0
OVERLAP_S = 15.0


class Overall(BaseModel):
    genre: str
    mood: str
    instruments: list[str]
    vocals: str
    production_style: str


class SectionNote(BaseModel):
    id: str
    label: str
    description: str
    what_changes: str


class ExtraMoment(BaseModel):
    approx_t: float
    what: str


class SpeechNote(BaseModel):
    tone: str
    emotion: str
    room: str
    noise: str


class Hearing(BaseModel):
    kind: str
    overall: Overall
    sections: list[SectionNote]
    extra_moments: list[ExtraMoment]
    mix_impressions: list[str]
    speech: SpeechNote


PROMPT = """You are listening to an audio clip for a motion designer and video editor.

Measured facts about this clip (trust these numbers; do not re-estimate them):
{skeleton}

Listen to the whole clip and fill the JSON schema:
- kind: one of music, speech, sfx, mixed.
- overall: genre, mood, instruments (list), vocals (describe them, or "none"), production_style.
- sections: one entry per measured section id, in order. label: a short name such as intro, verse, build, drop, chorus, break, bridge, outro; for speech use opening, point, aside, close. description: what you hear. what_changes: what differs from the previous section.
- extra_moments: notable events missing from the measured list, with approx_t in seconds from the start of this clip.
- mix_impressions: short observations about balance, space, dynamics and clarity.
- speech: tone, emotion, room, noise. Empty strings when there is no speech.
Be concrete and plain. No praise."""


def plan_chunks(duration: float, size: float = CHUNK_S, overlap: float = OVERLAP_S) -> list[tuple[float, float]]:
    if duration <= size:
        return [(0.0, float(duration))]
    chunks, start = [], 0.0
    while start < duration:
        end = min(start + size, float(duration))
        chunks.append((start, end))
        if end >= duration:
            break
        start = end - overlap
    return chunks


def build_prompt(data: dict, start: float, end: float) -> str:
    ingest = data.get("ingest") or {}
    rhythm = data.get("rhythm") or {}
    structure = data.get("structure") or {}
    kind = (data.get("classify") or {}).get("kind", "unknown")
    lines = [f"duration: {end - start:.1f} s", f"measured kind: {kind}"]
    if rhythm.get("bpm"):
        lines.append(f"tempo: {rhythm['bpm']:.1f} BPM, {rhythm.get('meter', 'unknown')} (confidence {rhythm.get('confidence', 0):.2f})")
    key = structure.get("key")
    if key:
        lines.append(f"key: {key['tonic']} {key['mode']} ({key['confidence']:.2f})")
    lines.append("sections:")
    for s in structure.get("sections", []):
        if s["end"] > start and s["start"] < end:
            lines.append(f"  {s['id']} {max(s['start'], start) - start:.2f} to {min(s['end'], end) - start:.2f} s, energy {s['energy']:.2f}")
    lines.append("moments:")
    for m in (data.get("moments") or {}).get("moments", []):
        if start <= m["t"] < end and m["type"] != "cut":
            lines.append(f"  {m['t'] - start:.2f} s {m['type']}")
    if ingest.get("has_video"):
        lines.append("this is the soundtrack of a video")
    return PROMPT.format(skeleton="\n".join(lines))


def merge(results: list[dict], chunks: list[tuple[float, float]]) -> dict:
    first = results[0]
    merged = {
        "kind": first["kind"],
        "overall": dict(first["overall"]),
        "sections": [],
        "extra_moments": [],
        "mix_impressions": [],
        "speech": first["speech"],
    }
    instruments = list(first["overall"].get("instruments", []))
    seen: set[str] = set()
    for r, (offset, _) in zip(results, chunks):
        for s in r["sections"]:
            if s["id"] not in seen:
                seen.add(s["id"])
                merged["sections"].append(s)
        for m in r["extra_moments"]:
            t = round(m["approx_t"] + offset, 2)
            if all(abs(t - x["approx_t"]) > 2 for x in merged["extra_moments"]):
                merged["extra_moments"].append({"approx_t": t, "what": m["what"]})
        for imp in r["mix_impressions"]:
            if imp not in merged["mix_impressions"]:
                merged["mix_impressions"].append(imp)
        for inst in r["overall"].get("instruments", []):
            if inst not in instruments:
                instruments.append(inst)
    merged["overall"]["instruments"] = instruments
    return merged


def get_backend(name: str) -> Callable:
    if name == "aistudio":
        from backends import aistudio

        return aistudio.hear
    if name == "gemini-cli":
        try:
            from backends import gemini_cli
        except ImportError:
            raise StageUnavailable("gemini-cli backend is not installed")
        return gemini_cli.hear
    raise StageUnavailable(f"unknown LISTEN_BACKEND {name!r}")


def _model(backend: str) -> str:
    if backend == "aistudio":
        from backends import aistudio

        return aistudio.model_name()
    return backend


def run(ctx: Context) -> dict:
    data = {s: ctx.data(s) for s in DEPS}
    duration = float(data["ingest"]["duration"])
    chunks = plan_chunks(duration)
    backend = os.environ.get("LISTEN_BACKEND", "aistudio")
    prompts = [build_prompt(data, a, b) for a, b in chunks]
    sha = hashlib.sha256((backend + "\n" + "\n".join(prompts)).encode()).hexdigest()[:16]
    prev = ctx.read("hear")
    if prev.get("prompt_sha") == sha and not prev.get("_unavailable"):
        return prev
    hear_fn = get_backend(backend)
    warnings, results = [], []
    for i, ((a, b), prompt) in enumerate(zip(chunks, prompts)):
        warn = usage.check_cap()
        if warn and warn not in warnings:
            warnings.append(warn)
        clip = ctx.path(f"hear_{i}.ogg")
        try:
            ffmpeg(["-i", str(ctx.path("master.wav")), "-ss", f"{a}", "-to", f"{b}",
                    "-ac", "1", "-ar", "16000", "-c:a", "libopus", "-b:a", "24k", str(clip)])
        except Fatal as e:
            raise StageUnavailable(f"could not prepare upload: {e}")
        try:
            results.append(hear_fn(clip, prompt, Hearing))
        except backends.RateLimited as e:
            raise StageUnavailable(f"rate limited: {e}")
        except backends.BackendError as e:
            raise StageUnavailable(str(e))
        usage.record()
    return {
        **merge(results, chunks),
        "prompt_sha": sha,
        "prompt_version": PROMPT_VERSION,
        "backend": backend,
        "model": _model(backend),
        "warnings": warnings,
        "notice": usage.first_upload_notice(backend),
    }
```

```python
def _labels(ctx: Context, sections: list[dict]) -> dict[str, str]:
    heard = {s["id"]: s["label"] for s in (ctx.data("hear") or {}).get("sections", []) if s.get("label")}

def _spectrogram(y, t0, path, title, sections, labels, downbeats, figsize):
    import librosa
    import librosa.display

    S = librosa.power_to_db(librosa.feature.melspectrogram(y=y, sr=SPEC_SR, n_mels=128, fmax=SPEC_SR / 2), ref=np.max)
    fig, ax = plt.subplots(figsize=figsize, dpi=100)
    x = t0 + librosa.times_like(S, sr=SPEC_SR)
    librosa.display.specshow(S, sr=SPEC_SR, x_coords=x, x_axis="time", y_axis="mel", fmax=SPEC_SR / 2, ax=ax, cmap="magma")
    t1 = t0 + len(y) / SPEC_SR
    top = ax.get_ylim()[1]
    for s in sections:
        if t0 <= s["start"] < t1:
            ax.axvline(s["start"], color="white", lw=1)
            ax.text(s["start"], top, f" {s['id']} {labels.get(s['id'], '')}", color="white", fontsize=9, va="top")
    db = [d for d in downbeats if t0 <= d < t1]
    if db:
        ax.plot(db, [ax.get_ylim()[0]] * len(db), ls="", marker="|", ms=10, color="#7fd4ff")
    ax.xaxis.set_major_formatter(_mmss)
    ax.set_title(title, fontsize=10)
    fig.tight_layout()
    fig.savefig(path)
    plt.close(fig)


def _lanes(ctx: Context, structure: dict, path) -> None:
    c = np.load(ctx.path(structure["curves_file"]))
    hz = structure["curve_hz"]
    names = [f"stem_{s}" for s in STEMS if f"stem_{s}" in c.files] or ["low", "mid", "high"]
    fig, axes = plt.subplots(len(names), 1, figsize=(16, 1.5 * len(names)), dpi=100, sharex=True)
    axes = np.atleast_1d(axes)
    for ax, name in zip(axes, names):
        v = c[name]
        t = np.arange(len(v)) / hz
        ax.fill_between(t, v, color="#e8590c", lw=0)
        ax.set_ylim(0, 1)
        ax.set_ylabel(name.replace("stem_", ""), fontsize=9)
        ax.xaxis.set_major_formatter(_mmss)
    axes[0].set_title("stem energy" if names[0].startswith("stem_") else "band energy (no stems)", fontsize=10)
    fig.tight_layout()
    fig.savefig(path)
    plt.close(fig)


def _ref(mix: dict, path) -> None:
    bands = list(mix["bands"])
    own = [mix["bands"][b] - mix["lufs"] for b in bands]
    ref = [mix["ref"]["bands"][b] - mix["ref"]["lufs"] for b in bands]
    fig, ax = plt.subplots(figsize=(12, 4), dpi=100)
    ax.plot(bands, own, marker="o", color="#e8590c", label="this mix")
    ax.plot(bands, ref, marker="o", color="#4c6ef5", label="reference")
    ax.set_ylabel("band level relative to LUFS (dB)")
    ax.set_title("spectral balance, loudness matched", fontsize=10)
    ax.legend(frameon=False)
    fig.tight_layout()
    fig.savefig(path)
    plt.close(fig)

    y, _ = librosa.load(str(ctx.path("master.wav")), sr=SPEC_SR, mono=True)
    structure = ctx.data("structure")

    if structure:
        _lanes(ctx, structure, ctx.path("stems.png"))
        images.append("stems.png")
        chosen = sorted(sorted(sections, key=lambda s: s["end"] - s["start"], reverse=True)[:MAX_SECTION_IMAGES],
                        key=lambda s: s["start"])
        for s in chosen:
            a, b = int(s["start"] * SPEC_SR), int(s["end"] * SPEC_SR)
            name = f"spec_{s['id']}.png"

            _spectrogram(y[a:b], s["start"], ctx.path(name), title, [s], labels, downbeats, (12, 4))
            images.append(name)
    mix = ctx.data("mix") or {}
    if mix.get("ref", {}).get("bands"):
        _ref(mix, ctx.path("ref.png"))
        images.append("ref.png")
    return {"images": images[:MAX_IMAGES]}
```

```python
"""Stage 8: cues.json and curves.json for code, report.md for Claude."""
from __future__ import annotations

import json

import numpy as np

from core.audio import norm01, resample_curve
from core.context import Context
from core.timefmt import fmt_time

VERSION = 1
DEPS = ("ingest", "stems", "rhythm", "hits", "classify", "structure", "moments", "mix", "speech", "hear", "see")
STEMS = ("vocals", "drums", "bass", "other")
SPARK = "▁▂▃▄▅▆▇█"
MAX_MOMENTS = 12
MAX_WORDS = 250
MAX_DESC = 140


def _f(t: float, fps: int) -> int:
    return int(round(float(t) * fps))


def _framed(e: dict, fps: int, key: str = "t") -> dict:
    out = {key: e[key], "f": _f(e[key], fps)}
    out.update({k: v for k, v in e.items() if k != key})
    return out


def build_cues(d: dict, fps: int) -> dict:
    ing = d.get("ingest") or {}
    rh = d.get("rhythm") or {}
    st = d.get("structure") or {}
    hear = d.get("hear") or {}
    heard = {s["id"]: s["label"] for s in hear.get("sections", []) if s.get("label")}
    sections = []
    for s in st.get("sections", []):
        label = heard.get(s["id"])
        sections.append({
            "id": s["id"], "label": label or s["label"], "start": s["start"], "end": s["end"],
            "f0": _f(s["start"], fps), "f1": _f(s["end"], fps), "energy": s["energy"],
            "label_source": "gemini" if label else "auto",
        })
    mix = d.get("mix")
    return {
        "version": 1,
        "source": {"file": ing.get("file"), "hash": d.get("_key"), "duration": ing.get("duration"), "fps": fps,
                   "kind": (d.get("classify") or {}).get("kind")},
        "tempo": {"bpm": rh.get("bpm"), "confidence": rh.get("confidence"), "meter": rh.get("meter"),
                  "changes": rh.get("changes", [])} if rh else None,
        "key": st.get("key"),
        "beats": [_framed(b, fps) for b in rh.get("beats", [])],
        "hits": {k: [_framed(h, fps) for h in v] for k, v in ((d.get("hits") or {}).get("hits") or {}).items()},
        "sections": sections,
        "moments": [_framed(m, fps) for m in (d.get("moments") or {}).get("moments", [])],
        "speech": [
            {"t0": s["t0"], "t1": s["t1"], "text": s["text"], "words": s.get("words", [])}
            for s in (d.get("speech") or {}).get("segments", [])
        ],
        "mix": {k: mix.get(k) for k in ("lufs", "true_peak", "lra", "clipped_samples", "flags")} if mix else None,
    }


def build_curves(ctx: Context, fps: int, duration: float) -> dict:
    out: dict[str, list[float]] = {}
    st = ctx.data("structure")
    if st:
        c = np.load(ctx.path(st["curves_file"]))
        hz = st["curve_hz"]
        out["energy"] = resample_curve(c["energy"], hz, fps, duration)
        for band in ("low", "mid", "high"):
            out[f"bands.{band}"] = resample_curve(c[band], hz, fps, duration)
        for s in STEMS:
            if f"stem_{s}" in c.files:
                out[f"stems.{s}"] = resample_curve(c[f"stem_{s}"], hz, fps, duration)
    mix = ctx.data("mix")
    if mix and mix.get("short_term", {}).get("values"):
        stv = mix["short_term"]
        vals = np.array(stv["values"], dtype=float)
        loud = norm01(vals, floor=max(-60.0, float(vals.min())))
        out["loudness"] = resample_curve(loud, stv["hz"], fps, duration, offset=stv["offset"])
    n = int(round(duration * fps))
    return {"fps": fps, "frames": n,
            "curves": {k: [round(float(x), 3) for x in np.clip(v, 0, 1)] for k, v in out.items()}}


def _section_at(sections: list[dict], t: float) -> dict | None:
    return next((s for s in sections if s["start"] <= t < s["end"]), None)


def find_conflicts(cues: dict, hear: dict, kind: str | None, images: list[str]) -> list[str]:
    out = []
    if not hear:
        return out
    measured = [m["t"] for m in cues["moments"] if m["type"] != "cut"]
    for em in hear.get("extra_moments", []):
        t = em["approx_t"]
        if not any(abs(t - x) <= 2.0 for x in measured):
            sec = _section_at(cues["sections"], t)
            img = f"spec_{sec['id']}.png" if sec and f"spec_{sec['id']}.png" in images else "spec_full.png"
            out.append(f"heard \"{em['what']}\" near {fmt_time(t, precise=True)}, nothing measured within 2 s; check {img}")
    hk = hear.get("kind")
    if hk and kind and hk != kind:
        out.append(f"measured kind is {kind}, hearing model says {hk}")
    missing = [s["id"] for s in cues["sections"] if s["label_source"] == "auto"]
    if missing:
        out.append(f"hearing model gave no label for {', '.join(missing)}; auto labels used")
    return out


def _spark(energy: list[float], fps: int, a: float, b: float, bins: int = 4) -> str:
    seg = energy[_f(a, fps):max(_f(a, fps) + 1, _f(b, fps))]
    if not seg:
        return ""
    chunks = np.array_split(np.array(seg), bins)
    return "".join(SPARK[min(7, int(c.mean() * 8))] if c.size else SPARK[0] for c in chunks)


def _clip(text: str, n: int = MAX_DESC) -> str:
    text = " ".join(str(text).split()).replace("|", "/")
    return text if len(text) <= n else text[: n - 3].rstrip() + "..."


def render_report(cues, d, curves, conflicts, unavailable, image_paths) -> str:
    src, tempo, key = cues["source"], cues.get("tempo"), cues.get("key")
    hear = d.get("hear") or {}
    head = [src.get("file") or "input", fmt_time(src.get("duration") or 0), src.get("kind") or "unknown"]
    if tempo and tempo.get("bpm") and (tempo.get("confidence") or 0) >= 0.5:
        head.append(f"{tempo['bpm']:.1f} BPM {tempo.get('meter')}")
    elif tempo:
        head.append("no steady beat")
    if key:
        head.append(f"{key['tonic']} {key['mode']} ({key['confidence']:.2f})")
    lines = ["# " + "  ·  ".join(head), ""]
    for w in (d.get("ingest") or {}).get("warnings", []) + hear.get("warnings", []):
        lines.append(f"Warning: {w}")
    if (d.get("ingest") or {}).get("silent"):
        lines += ["Input is silent. Nothing to analyse.", ""]

    lines.append("## What it sounds like (heard)")
    if hear.get("overall"):
        o = hear["overall"]
        lines.append(_clip(f"{o['genre']}, {o['mood']}. Instruments: {', '.join(o['instruments'])}. "
                           f"Vocals: {o['vocals']}. Production: {o['production_style']}.", 400))
        if hear.get("notice"):
            lines.append(f"Note: {hear['notice']}")
    else:
        lines.append("Hearing model not run (--fast, --no-cloud, or unavailable). Everything below is measured.")
    lines.append("")

    if cues["sections"]:
        energy = curves["curves"].get("energy", [])
        heard_desc = {s["id"]: s.get("description", "") for s in hear.get("sections", [])}
        lines += ["## Timeline (measured + heard)", "| # | label | time | energy | what is happening |", "|---|---|---|---|---|"]
        for s in cues["sections"]:
            inside = sorted({m["type"] for m in cues["moments"] if s["start"] <= m["t"] < s["end"] and m["type"] not in ("cut", "hold")})
            desc = heard_desc.get(s["id"]) or (f"measured: {', '.join(inside)}" if inside else "measured: steady")
            lines.append(f"| {s['id']} | {s['label']} | {fmt_time(s['start'])} to {fmt_time(s['end'])} | "
                         f"{_spark(energy, src['fps'], s['start'], s['end'])} | {_clip(desc)} |")
        lines.append("")

    events = [m for m in cues["moments"] if m["type"] not in ("cut", "hold")]
    top = sorted(sorted(events, key=lambda m: -m.get("strength", 0))[:MAX_MOMENTS], key=lambda m: m["t"])
    cuts = [m for m in cues["moments"] if m["type"] == "cut"]
    if top or cuts:
        lines.append("## Key moments (measured)")
        for m in top:
            span = f" to {fmt_time(m['end'], precise=True)}" if "end" in m else ""
            note = f": {m['note']}" if m.get("note") else ""
            lines.append(f"- {fmt_time(m['t'], precise=True)}{span} {m['type']} ({m.get('strength', 0):.2f}){note}")
        if len(events) > len(top):
            lines.append(f"- plus {len(events) - len(top)} more in cues.json")
        if cuts:
            lines.append("Best cuts: " + ", ".join(fmt_time(c["t"], precise=True) for c in sorted(cuts, key=lambda c: -c["strength"])[:6]))
        lines.append("")

    mix = d.get("mix")
    if mix:
        lines.append("## Mix (measured)")
        lines.append(f"{mix['lufs']:.1f} LUFS integrated  ·  true peak {mix['true_peak']:.1f} dBTP  ·  LRA {mix['lra']:.1f} LU  ·  "
                     f"width {mix.get('width', 0):.2f}  ·  clipped {mix['clipped_samples']}")
        lines.append("Flags: " + ("; ".join(mix["flags"]) if mix["flags"] else "none"))
        if hear.get("mix_impressions"):
            lines.append("Heard: " + _clip("; ".join(hear["mix_impressions"]), 300))
        ref = mix.get("ref")
        if ref:
            lines.append(f"Reference {ref['file']}: " + (ref.get("error") or ("; ".join(ref["deltas"]) or "no differences over 3 dB")))
        lines.append("")

    segs = (d.get("speech") or {}).get("segments", [])
    if segs:
        words = " ".join(s["text"] for s in segs).split()
        lines.append("## Speech (measured)")
        sp = hear.get("speech") or {}
        if any(sp.get(k) for k in ("tone", "emotion", "room", "noise")):
            lines.append(_clip(f"Heard: tone {sp['tone']}, emotion {sp['emotion']}, room {sp['room']}, noise {sp['noise']}", 300))
        pauses = (d.get("speech") or {}).get("pauses", [])
        lines.append(f"{len(segs)} segments, {len(words)} words, {len(pauses)} pauses over 0.4 s")
        lines.append(" ".join(words[:MAX_WORDS]) + (" ... (full transcript in cues.json)" if len(words) > MAX_WORDS else ""))
        lines.append("")

    lines.append("## Conflicts")
    lines += [f"- {c}" for c in conflicts] or ["none"]
    lines.append("")
    if unavailable:
        lines.append("## Status")
        lines += [f"- {k}: unavailable: {v}" for k, v in unavailable.items()]
        lines.append("")
    lines.append("## Images")
    lines += [f"- {p}" for p in image_paths] or ["none"]
    return "\n".join(lines) + "\n"


def run(ctx: Context) -> dict:
    d = {s: ctx.data(s) for s in DEPS}
    d["_key"] = ctx.workdir.name
    duration = float((d.get("ingest") or {}).get("duration") or 0.0)
    cues = build_cues(d, ctx.fps)
    curves = build_curves(ctx, ctx.fps, duration)
    images = (d.get("see") or {}).get("images", [])
    conflicts = find_conflicts(cues, d.get("hear") or {}, (d.get("classify") or {}).get("kind"), images)
    unavailable = {s: ctx.read(s)["_unavailable"] for s in DEPS if ctx.read(s).get("_unavailable")}
    report = render_report(cues, d, curves, conflicts, unavailable, [str(ctx.path(i)) for i in images])
    ctx.path("cues.json").write_text(json.dumps(cues, indent=1))
    ctx.path("curves.json").write_text(json.dumps(curves, separators=(",", ":")))
    ctx.path("report.md").write_text(report)
    return {"files": ["report.md", "cues.json", "curves.json"], "conflicts": len(conflicts)}
```

```python
"""The ordered stage list and when each stage runs."""
from __future__ import annotations

from core.context import Context
from core.pipeline import Stage
from stages import assemble, classify, hear, hits, ingest, mix, moments, rhythm, see, speech, stems, structure


def _ingest(ctx: Context) -> dict:
    return ctx.data("ingest") or {}


def _playable(ctx: Context) -> bool:
    return not _ingest(ctx).get("silent")


def _analysable(ctx: Context) -> bool:
    i = _ingest(ctx)
    return not i.get("silent") and not i.get("short")


def _speech_enabled(ctx: Context) -> bool:
    if ctx.fast or not _playable(ctx):
        return False
    c = ctx.data("classify") or {}
    ratio = (c.get("features") or {}).get("vocal_ratio")
    return c.get("kind") in ("speech", "mixed") or (ratio is not None and ratio >= 0.1)


def _stage(mod, name, enabled=None) -> Stage:
    if enabled is None:
        return Stage(name, mod.VERSION, mod.DEPS, mod.run)
    return Stage(name, mod.VERSION, mod.DEPS, mod.run, enabled)


def build_stages() -> list[Stage]:
    return [
        _stage(ingest, "ingest"),
        _stage(stems, "stems", lambda c: not c.fast and _analysable(c)),
        _stage(rhythm, "rhythm", _analysable),
        _stage(hits, "hits", _analysable),
        _stage(classify, "classify", _playable),
        _stage(structure, "structure", _analysable),
        _stage(moments, "moments", _analysable),
        _stage(mix, "mix", _playable),
        _stage(speech, "speech", _speech_enabled),
        _stage(hear, "hear", lambda c: not c.fast and not c.no_cloud and _playable(c)),
        _stage(see, "see", _playable),
        _stage(assemble, "assemble"),
    ]
```

```python
#!/usr/bin/env python3
"""/listen: give Claude an ear. Usage is documented in SKILL.md."""
from __future__ import annotations

import argparse
import shutil
import sys
from pathlib import Path

from core import config
from core.cache import cache_root, source_key
from core.context import Context
from core.pipeline import Fatal, run_pipeline
from core.registry import build_stages
from core.timefmt import parse_time
from stages.ingest import resolve_source


def _parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="listen", description="Listen to audio, a URL or a video soundtrack.")
    p.add_argument("source")
    p.add_argument("question", nargs="?")
    p.add_argument("--fast", action="store_true", help="skip stems and the hearing model")
    p.add_argument("--start", help="SS, MM:SS or HH:MM:SS")
    p.add_argument("--end", help="SS, MM:SS or HH:MM:SS")
    p.add_argument("--fps", type=int, default=60)
    p.add_argument("--ref", help="reference track for mix comparison")
    p.add_argument("--no-cloud", action="store_true", help="never upload audio")
    p.add_argument("--stages", default="", help="comma-separated stages to force rerun")
    p.add_argument("--export", help="copy cues.json and curves.json into this folder")
    return p


def run(argv: list[str]) -> tuple[int, dict]:
    a = _parser().parse_args(argv)
    config.load_env()
    try:
        start = parse_time(a.start) if a.start else None
        end = parse_time(a.end) if a.end else None
        downloads = cache_root() / "downloads"
        src = resolve_source(a.source, downloads)
        workdir = cache_root() / source_key(src, start, end)
        workdir.mkdir(parents=True, exist_ok=True)
        options = {"source": str(src), "start": start, "end": end}
        if a.ref:
            options["ref"] = str(resolve_source(a.ref, downloads))
        ctx = Context(workdir=workdir, fps=a.fps, fast=a.fast, no_cloud=a.no_cloud, options=options)
        force = {s.strip() for s in a.stages.split(",") if s.strip()} | {"assemble"}
        if a.ref or ctx.read("mix").get("ref"):
            force.add("mix")
        status = run_pipeline(ctx, build_stages(), force=force)
    except (Fatal, ValueError) as e:
        print(f"listen: {e}", file=sys.stderr)
        return 2, {"status": {}, "workdir": None}
    if a.export:
        dest = Path(a.export).expanduser()
        dest.mkdir(parents=True, exist_ok=True)
        for name in ("cues.json", "curves.json"):
            shutil.copy2(workdir / name, dest / name)
    return 0, {"status": status, "workdir": workdir}


def main() -> None:
    code, info = run(sys.argv[1:])
    if code == 0:
```

```python
Exit codes: 0 ready, 2 missing binaries, 3 missing API key, 4 both, 5 Python environment not installed.
"""

import platform

import sys

BINARIES = ("ffmpeg", "ffprobe", "yt-dlp", "uv")

# LISTEN_DAILY_CAP=200
# LISTEN_WHISPER_MODEL=mlx-community/whisper-large-v3-turbo
"""

    2: "missing binaries: {missing}. Run: python3 {here}/setup.py",
    3: "no GEMINI_API_KEY in {env}. Add one, or run listen with --no-cloud.",
    4: "missing binaries ({missing}) and no GEMINI_API_KEY. Run: python3 {here}/setup.py",
    5: "Python environment not installed. Run: python3 {here}/setup.py",
}


def read_env() -> dict:
    env = {}
    if ENV_FILE.exists():
        for line in ENV_FILE.read_text().splitlines():
            line = line.strip()
            if line and not line.startswith("#") and "=" in line:
                k, v = line.split("=", 1)
                env[k.strip()] = v.strip().strip('"').strip("'")
    env.update({k: v for k, v in os.environ.items() if k.startswith(("LISTEN_", "GEMINI_"))})
    return env


def status() -> dict:
    env = read_env()
    missing = [b for b in BINARIES if not shutil.which(b)]
    backend = env.get("LISTEN_BACKEND", "aistudio")
    has_key = backend != "aistudio" or bool(env.get("GEMINI_API_KEY"))
    env_ready = READY_MARKER.exists()
    if missing and not has_key:
        code = 4
    elif missing:
        code = 2
    elif not env_ready:
        code = 5
    elif not has_key:
        code = 3
    else:
        code = 0
    return {
        "status_code": code,
        "missing_binaries": missing,
        "backend": backend,
        "has_key": has_key,
        "env_ready": env_ready,
        "config_file": str(ENV_FILE),
        "platform": platform.platform(),
    }


def scaffold_env() -> None:
    ENV_FILE.parent.mkdir(parents=True, exist_ok=True)
    if not ENV_FILE.exists():
        ENV_FILE.write_text(ENV_TEMPLATE)
    os.chmod(ENV_FILE, 0o600)


def install() -> dict:
    missing = [b for b in BINARIES if not shutil.which(b)]
    if missing and shutil.which("brew"):
        subprocess.run(["brew", "install", *sorted({BREW_PACKAGES[b] for b in missing})], check=False)
    elif missing:
        print(f"install these with your package manager: {', '.join(missing)}")
    if shutil.which("uv"):
        r = subprocess.run(["uv", "sync", "--project", str(HERE)], check=False)
        if r.returncode == 0:
            READY_MARKER.parent.mkdir(parents=True, exist_ok=True)
            READY_MARKER.touch()
    scaffold_env()
    return status()

    """Download model weights once so the first real run is fast."""
    py = ["uv", "run", "--project", str(HERE), "python", "-c"]
    subprocess.run([*py, "from beat_this.inference import File2Beats; File2Beats(checkpoint_path='final0', device='cpu')"], check=False)

                         "path_or_hf_repo='mlx-community/whisper-large-v3-turbo')"], check=False)


def main() -> None:
    p = argparse.ArgumentParser()
    p.add_argument("--check", action="store_true")
    p.add_argument("--json", action="store_true")
    p.add_argument("--prefetch", action="store_true")

        sys.exit(s["status_code"])
    s = install()
    if a.prefetch:
        prefetch()
    print(json.dumps(s, indent=1))
    sys.exit(s["status_code"])


if __name__ == "__main__":
    main()
```

```ts
// Pure helpers for driving animation from /listen output. No dependencies.

export type Beat = { t: number; f: number; bar: number; beat: number; strength: number };
export type Hit = { t: number; f: number; v: number };
export type Moment = { t: number; f: number; type: string; strength?: number; end?: number; note?: string };
export type Section = {
  id: string;
  label: string;
  start: number;
  end: number;
  f0: number;
  f1: number;
  energy: number;
  label_source: string;
};
export type Cues = {
  version: number;
  source: { file: string; hash: string; duration: number; fps: number; kind: string };
  beats: Beat[];
  hits: Record<string, Hit[]>;
  sections: Section[];
  moments: Moment[];
};
export type Curves = { fps: number; frames: number; curves: Record<string, number[]> };

type Framed = { f: number };

export function lastAtOrBefore<T extends Framed>(events: T[], frame: number): number {
  let lo = 0;
  let hi = events.length - 1;
  let ans = -1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (events[mid].f <= frame) {
      ans = mid;
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }
  return ans;
}

/** 1 on the most recent event, easing exponentially to 0. */
export function pulse(frame: number, events: Framed[], decay = 8): number {
  const i = lastAtOrBefore(events, frame);
  if (i < 0) return 0;
  return Math.exp(-(frame - events[i].f) / Math.max(decay, 1e-6));
}

export function beatPulse(
  frame: number,
  beats: Beat[],
  opts: { decay?: number; downbeatOnly?: boolean } = {},
): number {
  const list = opts.downbeatOnly ? beats.filter((b) => b.beat === 1) : beats;
  return pulse(frame, list, opts.decay ?? 8);
}

export function curveAt(curves: Curves, name: string, frame: number): number {
  const c = curves.curves[name];
  if (!c || c.length === 0) return 0;
  const x = Math.min(Math.max(frame, 0), c.length - 1);
  const i = Math.floor(x);
  const j = Math.min(i + 1, c.length - 1);
  return c[i] + (c[j] - c[i]) * (x - i);
}

export function momentAt(frame: number, moments: Moment[], type: string, tolerance = 0): Moment | null {
  for (const m of moments) {
    if (m.type === type && Math.abs(frame - m.f) <= tolerance) return m;
  }
  return null;
}

export function sectionAt(frame: number, sections: Section[]): Section | null {
  return sections.find((s) => s.f0 <= frame && frame < s.f1) ?? null;
}
```

`backends/gemini_cli.py`:

```python
"""Gemini through the Gemini CLI, signed in with a personal Google account.

Experimental. The CLI has no response-schema option, so the prompt carries the
JSON Schema and the reply is validated with pydantic.
"""
from __future__ import annotations

import json
import re
import shutil
import subprocess
from pathlib import Path

from pydantic import BaseModel, ValidationError

from backends import BackendError, RateLimited

TIMEOUT_S = 300


def _strip_fences(text: str) -> str:
    m = re.search(r"```(?:json)?\s*(.*?)```", text, re.S)
    return (m.group(1) if m else text).strip()


def hear(audio: Path, prompt: str, schema_model: type[BaseModel], **_) -> dict:
    exe = shutil.which("gemini")
    if not exe:
        raise BackendError("gemini CLI not found")
    audio = Path(audio)
    schema = json.dumps(schema_model.model_json_schema())
    full = f"{prompt}\n\nReturn only JSON that matches this JSON Schema:\n{schema}\n\nThe audio: @{audio.name}"
    try:
        r = subprocess.run([exe, "-p", full, "--output-format", "json"], capture_output=True, text=True,
                           timeout=TIMEOUT_S, cwd=str(audio.parent))
    except subprocess.TimeoutExpired:
        raise BackendError("gemini CLI timed out")
    if r.returncode != 0:
        err = (r.stderr or r.stdout)[-300:]
        if "429" in err or "quota" in err.lower():
            raise RateLimited(err)
        raise BackendError(f"gemini CLI failed: {err}")
    try:
        text = json.loads(r.stdout)["response"]
        return schema_model.model_validate_json(_strip_fences(text)).model_dump()
    except (KeyError, json.JSONDecodeError, ValidationError) as e:
        raise BackendError(f"gemini CLI returned unusable output: {e}")
```

```python
import json
from pathlib import Path

import numpy as np
import pytest

import listen

GOLDEN = Path(__file__).parent / "golden"
CASES = sorted(p for p in GOLDEN.glob("*") if (p / "truth.json").exists() and list(p.glob("audio.*")))


@pytest.mark.models
@pytest.mark.parametrize("case", CASES, ids=[c.name for c in CASES])
def test_golden(case, tmp_path, monkeypatch):
    monkeypatch.setenv("LISTEN_CACHE", str(tmp_path / "cache"))
    truth = json.loads((case / "truth.json").read_text())
    audio = next(case.glob("audio.*"))
    code, info = listen.run([str(audio), "--no-cloud"])
    assert code == 0
    cues = json.loads((info["workdir"] / "cues.json").read_text())
    assert abs(cues["tempo"]["bpm"] - truth["bpm"]) <= 1.0
    beats = np.array([b["t"] for b in cues["beats"]])
    errors = np.array([np.min(np.abs(beats - t)) for t in truth["downbeats"]])
    assert np.percentile(errors, 90) <= 1 / 60, f"downbeat errors: {errors}"
    drops = np.array([m["t"] for m in cues["moments"] if m["type"] == "drop"])
    for t in truth.get("drops", []):

    starts = np.array([s["start"] for s in cues["sections"]])
    hits = sum(np.min(np.abs(starts - t)) <= 2.0 for t in truth.get("section_starts", []))
```

```tsx
import { AbsoluteFill, Audio, staticFile, useCurrentFrame } from "remotion";
import cuesJson from "../public/cues.json";
import curvesJson from "../public/curves.json";
import { beatPulse, momentAt, useCues, type Cues, type Curves } from "./lib/cues";

export const SyncTest = () => {
  const frame = useCurrentFrame();
  const { beats, moments, curve } = useCues(cuesJson as unknown as Cues, curvesJson as unknown as Curves);
  const pulse = beatPulse(frame, beats, { decay: 6 });
  const down = beatPulse(frame, beats, { decay: 10, downbeatOnly: true });
  const drop = momentAt(frame, moments, "drop", 2);
  const bass = curve("bands.low", frame);
  const size = 300 + 400 * bass;
  return (
    <AbsoluteFill style={{ background: drop ? "#f2f2f2" : "#0b0b0f", alignItems: "center", justifyContent: "center" }}>
      <Audio src={staticFile("audio.wav")} />
      <div
        style={{
          width: size,
          height: size,
          borderRadius: "50%",
          background: `rgba(232, 89, 12, ${0.25 + 0.75 * pulse})`,
          border: `${2 + 18 * down}px solid #f2f2f2`,
        }}
      />
      <div style={{ position: "absolute", bottom: 60, color: "#7fd4ff", fontFamily: "monospace", fontSize: 36 }}>
        {`frame ${frame}`}
      </div>
    </AbsoluteFill>
  );
};
```
